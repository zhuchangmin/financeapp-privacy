隐私政策

最后更新日期：2026 年 7 月

核心承诺

本应用是一款纯本地记账工具。财务数据默认保存在您的设备本机。开发者无法访问、查看或收集您的任何财务数据。

我们不收集的信息

  • 不收集身份信息
  • 不收集银行账户、信用卡号
  • 不收集交易流水、收支记录
  • 不收集位置信息
  • 不使用第三方分析或广告 SDK
  • 不跨 App 追踪用户

设备上存储的信息

以下数据默认存储在您的设备本地：

  • 收支流水记录
  • 账户信息
  • 分类设置
  • 应用偏好

数据导出

您可以在应用内主动导出 CSV 或 JSON 备份文件，并自行决定保存位置。

数据安全

  • 默认设备本地存储
  • 支持 Face ID / Touch ID 生物识别锁定
  • 删除应用即彻底清除所有本地数据

您的权利（依据《个人信息保护法》）

  • 随时查看应用内所有数据
  • 通过导出功能导出数据
  • 删除应用即完全删除数据

如有隐私相关问题，请通过 App Store 联系开发者。
